app.get("/user", (req, res, next) => {
    // This is Router Handler function
    //res.send("Router Handler 1")
    console.log("Handling the route user!!!")
     res.send("Response!!")
    next(); // will go to next route handler
}, 
(req, res) => {
    console.log("Handling the route user 2!!")
    res.send("2nd Response!!")
}
); -> it will print Response, the tcp connection made betweeen client and server is closed now as the response from the 1st route handler is made, now it will not make any response for 2nd route handler as the connection is already closed now after handling 1st route handler response. Don't write the code like this at all.



app.get("/user", (req, res, next) => {
    // This is Router Handler function
    //res.send("Router Handler 1")
    console.log("Handling the route user!!!")
    
    next(); // will go to next route handler
    res.send("Response!!")
}, 
(req, res) => {
    console.log("Handling the route user 2!!")
    res.send("2nd Response!!")
}
); -> 2nd Response will come in the output. because you are trying to send response again to the client when the request is already fullfilled. or we can say like this: the tcp connection made betweeen client and server is closed now as the response from the 1st route handler is made, now it will not make any response for 2nd route handler as the connection is already closed now after handling 1st route handler response.
